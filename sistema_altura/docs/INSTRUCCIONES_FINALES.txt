INSTRUCCIONES FINALES - Sistema de Predicción de Estatura (TFLite)
════════════════════════════════════════════════════════════════════

✅ PROYECTO ACTUALIZADO A TENSORFLOW LITE

• Modelo: DNN convertido a .tflite (inferencia rápida y ligera)
• Python 3.12: usa TensorFlow (tf.lite.Interpreter) como fallback
• Python < 3.12: usa tflite-runtime (más ligero)
• Auto-captura: cuenta regresiva de 3 segundos cuando detección es "EXCELENTE"
• Calibración: ajuste por offset aditivo contra tu estatura real

✅ Scripts y utilidades disponibles:

Python (scripts/):
  • predicciones_headless.py  - Inferencia sin GUI (por lotes)
  • analizar_offsets.py       - Análisis de calibraciones/resultados
  • entrenar_dnn_altura.py    - (Opcional) Entrenamiento DNN
  • generar_dataset_sintetico.py - (Opcional) Datos sintéticos

Programa principal:
  • app/captura_y_prediccion.py - GUI con captura y calibración


════════════════════════════════════════════════════════════════════
CONFIGURACIÓN INICIAL (Primera vez)
════════════════════════════════════════════════════════════════════

1. Crear entorno virtual:
   python3 -m venv venv

2. Activar entorno:
   source venv/bin/activate

3. Instalar dependencias:
   pip install --upgrade pip setuptools wheel
   pip install -r requirements.txt

4. Verificar instalación:
   python -c "import cv2, mediapipe, numpy, PIL, joblib, sklearn; print('OK')"


════════════════════════════════════════════════════════════════════
EJECUCIÓN DIARIA
════════════════════════════════════════════════════════════════════

Después de configurar el entorno (una sola vez), para usar el sistema
cada día:

1. Activar entorno:
   source venv/bin/activate

2. Ejecutar la GUI:
   python app/captura_y_prediccion.py

   La cámara se enciende automáticamente. Sigue las guías en pantalla.
   Cuando la calidad sea "EXCELENTE", comenzará una cuenta regresiva
   de 3 segundos y se realizará la captura automáticamente.

3. Calibrar (opcional):
   - Ingresa tu estatura real en la UI.
   - El sistema calcula el offset usando la predicción sin calibración
     y lo guarda en modelos/calibracion_*.json


════════════════════════════════════════════════════════════════════
USO AVANZADO
════════════════════════════════════════════════════════════════════

📌 Predicciones sin GUI (headless)
   Ahora el script soporta tres modos de ejecución:

   1) Desde la cámara (sin GUI):
      python scripts/predicciones_headless.py --num 5 --device 0 --cooldown 1.5

   2) Procesar una carpeta de imágenes (hasta N):
      python scripts/predicciones_headless.py --images-dir ./capturas_estatura --num 10

   3) Procesar una sola imagen:
      python scripts/predicciones_headless.py --image ./capturas_estatura/mi_foto.jpg

   Salida:
   • Imagen anotada y JSON por predicción en resultados_predicciones/
   • El JSON incluye: altura_predicha_cm (calibrada), altura_sin_calibracion_cm (cruda),
     confianza, visibilidad_landmarks y características clave (px)
   • Extensiones soportadas: .jpg/.jpeg/.png

📌 Análisis de offsets y calibración
   Analiza estadísticas de calibraciones y predicciones headless:

   python scripts/analizar_offsets.py

   Muestra tabla con Raw, Calibrada, Offset y Confianza; más estadísticas
   (media, desviación, rango) para evaluar estabilidad y precisión.

📌 Entrenamiento de modelos (opcional)
   Si quieres entrenar un nuevo modelo DNN:

   python scripts/entrenar_dnn_altura.py --csv datos.csv --output modelos/

   Generará: modelo_altura_*.tflite, scaler_*.pkl, modelo_metadata_*.json

   Para datos sintéticos de prueba:
   python scripts/generar_dataset_sintetico.py --output datos_sinteticos.csv --num 1000

SOLUCIÓN DE PROBLEMAS
════════════════════════════════════════════════════════════════════

❌ Error: ModuleNotFoundError: No module named 'mediapipe'
   Solución: Activa el venv antes de ejecutar
      source venv/bin/activate
      python app/captura_y_prediccion.py

❌ Error: No se pudo abrir la cámara
   Solución: Verifica permisos y dispositivo
      ls -l /dev/video*
      # Si falla, prueba con otro índice:
      # En captura_y_prediccion.py, cambiar: cv2.VideoCapture(0) → cv2.VideoCapture(1)

❌ Predicciones muy altas o bajas (ej. >250 cm o <100 cm)
   Solución: Calibra con tu estatura real en la UI o edita manualmente
      modelos/calibracion_*.json

❌ Numpy version warning
   Solución: Fijar numpy==2.1.3 en requirements.txt si persiste
